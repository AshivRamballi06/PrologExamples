# Prolog Recursive List Processing Examples

A collection of **Prolog exercises** focused on recursive list processing, filtering, transformation, counting and consecutive-pair problems.

I created these examples while learning logic programming and working with recursive predicates in **SWI-Prolog**.

## Examples Included

The repository contains examples such as:

* Filtering positive and negative values
* Counting values that match specific conditions
* Summing selected values
* Removing values from lists
* Doubling and transforming values
* Counting consecutive matching and non-matching pairs
* Comparing neighbouring values
* Working with thresholds
* Recursive list traversal

## Concepts Demonstrated

* Prolog recursion
* Pattern matching using `[H|T]`
* Base and recursive cases
* List filtering
* List transformation
* Arithmetic operations
* Conditional logic
* Consecutive pair processing
* Numeric comparisons

## Technologies

* Prolog
* SWI-Prolog

## Running the Examples

Open any `.pl` file in SWI-Prolog and consult it.

For example:

```prolog
?- [src/'FilterPositiveValues.pl'].
```

You can then call the predicate defined in that file.
